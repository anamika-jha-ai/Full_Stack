# 🚀 Full Stack Web Development

Welcome to my **Full Stack Web Development** repository! 

This repository documents my journey of learning and exploring web development, starting from the fundamentals of HTML and CSS to JavaScript and backend development using Node.js, Express.js and MongoDB.

It contains practice exercises, mini-projects, clones and hands-on implementations created while learning the MERN stack.

## 🛠️ Technologies & Tools

| Technology | Purpose |
|---|---|
| HTML5 | Structure of web pages |
| CSS3 | Styling and responsive layouts |
| JavaScript | Frontend logic and interactivity |
| Node.js | Backend runtime environment |
| Express.js | Backend framework |
| MongoDB | NoSQL database |
| Git & GitHub | Version control |

## 💻 Getting Started

To explore this repository locally:

1. Clone the repository:

```bash
git clone https://github.com/anamika-jha-ai/Full_Stack.git
```

2. Navigate into the project directory:

```bash
cd Full_Stack
```

3. Open the repository in VS Code:

```bash
code .
```

4. Explore individual folders and projects.

For backend projects, navigate to the respective project directory, install dependencies and follow its setup instructions.
